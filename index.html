Set up resources

      
Deploy a dedicated demo with fictional data, or skip deployment if your Search service already has the required resources.

      
      
      
      

        

          
Base resources

          
          
          
          
          
          
          
          
          

            
Full-suite deployment uploads a fictional text file to a private Azure Blob Storage container for Entity Graph. See the upload and ingestion flow.

            
            
            
            
            
The Blob account must already have a dedicated NSP profile. The deployer adds one inbound Search IP rule to that profile and grants the Search identity Blob Reader at account scope. It never edits the Storage firewall. Your egress IP must already be permitted by the Storage NSP for uploads.

          

          
Creates an Entra-only Basic Search service with Standard Knowledge Retrieval and reuses configured Foundry models. Your notes stay untouched.

          
          

        

        

          
Topic Graph resources

          
Graph Lab builds a topic graph with Microsoft's Topic Graph tooling, publishes the content and topic indexes, and then attaches the Search index knowledge source to a knowledge base.

          
To provision these resources, select the full suite in Base. The examples below show the setup calls without deploying anything.

        

        

          
Entity Graph resources

          
Full-suite deployment uploads graph-lab-fictional.txt to the private container using Microsoft Entra. If that blob already exists, Graph Lab leaves it in place. The deployment does not upload your NoteAssistant files.

          
To provision these resources, select the full suite and configure Blob Storage and networking in Base.

          
View the knowledge source creation code or inspect the managed index names in the Entity Graph tutorial.
